---

## 📌 Sobre o Repositório

Este espaço serve como um portfólio de evolução e aprendizado contínuo. Aqui estão reunidos arquivos de práticas que vão desde os conceitos mais básicos da estruturação web até a estilização avançada e responsividade.

### 🚀 Principais Tópicos Estudados:
* **HTML5:** Estruturação semântica de páginas, tabelas, formulários, incorporação de mídias (áudio/vídeo) e boas práticas de acessibilidade.
* **CSS3:** Seletores, box model, posicionamento, tipografia, cores, gradientes e introdução ao design responsivo.
* **Versionamento:** Uso do Git e GitHub para organizar o fluxo de trabalho e o histórico do código.

---

## 🛠️ Tecnologias Utilizadas

* [HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML) - Linguagem de marcação de texto.
* [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS) - Mecanismo de estilização e design.
* [Visual Studio Code](https://code.visualstudio.com/) - Editor de código (IDE).
